## Картинки в pencode

ID мода: PENCODE_IMAGES

### Описание мода

Тег `[img]ссылка[/img]` вставляет картинку по ссылке. Он работает везде, где работает pencode:
на бумаге, в письмах, документах NanoWord, отчётах и данных сканеров, потому что и бумага,
и компьютеры переводят pencode в HTML через `pencode2html()`.

Ссылка проходит проверку: только `https://`, хост целиком совпадает с одним из списка
в конфиге `config/image_hosts.txt`, а в пути и параметрах разрешены только буквы, цифры и `_ . / % ~ + - = & ;`.
Кавычки, пробелы, `<`, `>`, `@`, `:` и `#` не проходят, поэтому ссылка не может выйти из атрибута `src`.
Ссылка, которая не прошла проверку, остаётся на странице обычным текстом.

Белый список нужен ради приватности: картинку скачивает клиент каждого читателя напрямую с хостинга,
и хостинг видит его IP. Со своего сервера игрок мог бы собрать IP всех, кто открыл его письмо или бумагу.
В список добавляем только крупные хостинги, которые не показывают загрузившему, кто смотрел файл,
без открытых редиректов и без поддоменов, которые могут создавать пользователи.

#### Конфиг

Список хостов лежит в `config/image_hosts.txt`, по одному хосту на строку, строки с `#` - комментарии.
Образец с правилами - `config/example/image_hosts.txt`.
Если файла нет - разрешённых хостов тоже нет, в лог пишется предупреждение.

Ограничения:

- не больше 5 картинок за одну запись на бумаге и на один цифровой файл, остальные теги остаются текстом;
- картинка показывается не шире окна и не выше 400 пикселей;
- на бумаге каждая картинка занимает столько места, сколько её ссылка

Сканер бумаги переводит картинки обратно в `[img]` через `html2pencode()`.

#### Логи для администрации

Каждая картинка записывается с сикеем автора, когда игрок пишет на бумаге или печатает её, отправляет письмо,
сохраняет файл в NanoWord или заполняет текстовое поле отчёта:

- `game.log`: строка `IMAGES:` на каждую запись со ссылками;
- админский глагол `Investigate` → `images`: все записи раунда со ссылками и кнопкой `VIEW`;
- чат стаффа с правом investigate (админы и модераторы): строка `IMAGE:` с кнопками `VIEW`, `LOC`, `MOB`,
  когда игрок впервые за раунд выкладывает ссылку. Повтор той же ссылки тем же игроком в чат не пишется.
  Отключается в настройках стаффа: `Image Log Messages`.

`VIEW` открывает окно: кто, где, картинки размыты до клика (повторный клик размывает снова),
под ними начало текста записи. Окно закрывается кнопкой `Close` или клавишей Esc.
